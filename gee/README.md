# Google Earth Engine processing

The Earth Engine scripts will be added here after the frontend is verified. The initial pilot should use the Rawalpindi–Islamabad boundary, small test regions and cloud-side processing. Export only small summaries or tiles needed by the web app; avoid exporting full-resolution rasters unnecessarily.

Before connecting public services, confirm account/project setup, access permissions, quotas and the current Earth Engine terms that apply to the intended use.
